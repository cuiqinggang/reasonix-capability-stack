# /memory trial-status — 试运行状态仪表盘

> 轻量入口：完整治理规则见 `C:\Users\A\.codex\knowledge-brain\reasonix\MEMORY_GOVERNANCE.md`

---

## 用途

显示候选记忆审核流水线的试运行进度。追踪三个真实任务的完成情况、候选统计和系统健康度。

## 数据来源

| 数据项 | 来源路径 |
|--------|----------|
| 任务进度 | `.reasonix\reports\` 中试运行任务报告 |
| candidate 数 | `incoming\reasonix-memory-candidates\` status=candidate |
| active 新增 | `reasonix\` 试运行期间新增 |
| 拒绝数 | status=rejected |
| 候选池用量 | 候选目录文件数 / 30 |

## 显示维度

### 1. 真实任务进度（目标 3/3）

```
[▓▓░░░░░░] 0/3  →  [▓▓▓▓▓▓░░] 2/3  →  [▓▓▓▓▓▓▓▓▓▓] 3/3 ✅
```

### 2. 候选统计

| 指标 | 试运行要求 |
|------|-----------|
| 当前 candidate | 累计 |
| active 新增 | **必须为 0**（试运行不激活） |
| 已拒绝 | 累计 |
| 重复（去重拒绝） | 累计 |
| Gate APPROVE | 待用户确认激活 |

### 3. 候选池用量

- < 20：🟢 OK
- 20–26：🟡 WATCH
- 27–30：🔴 CRITICAL（暂停提交新候选）

### 4. 反膨胀状态

| 规则 | 上限 | 当前 |
|------|------|------|
| 候选池总量 | 30 | [N] |
| 核心摘要字符数 | 1,200 | [N] |
| 本次 candidate | 3 | [N] |
| 本次 active | 1 | 0 |
| >30天未审核 | 0 | [N] |
| 同义重复对 | 0 | [N] |
