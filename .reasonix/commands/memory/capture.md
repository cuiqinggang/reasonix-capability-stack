# /memory capture — 候选记忆提取

> 轻量入口：完整治理规则见 `C:\Users\A\.codex\knowledge-brain\reasonix\MEMORY_GOVERNANCE.md`

---

## 用途

真实任务完成后，提取最多 3 条候选记忆写入候选池。

## 前置条件

- 任务已完成，有验收证据（报告/测试/用户确认）
- 候选池未满（< 30 条）
- 任务有可追溯的 task ID

## 准入检查（6 条，至少满足 2 条）

| # | 条件 |
|---|------|
| A1 | 用户明确要求"以后记住" |
| A2 | 同类偏好/错误/规则重复出现 |
| A3 | 有验收报告、测试结果或用户确认 |
| A4 | 对未来多个任务有长期价值 |
| A5 | 不记录就很难重新获得 |
| A6 | 能明确写出适用范围和失效条件 |

**< 2 条 → REJECT**

## 拒绝检查（9 条，全部必须为否）

| # | 条件 |
|---|------|
| R1 | 普通闲聊 |
| R2 | 原始对话全文 |
| R3 | 模型猜测 |
| R4 | 未验证结论 |
| R5 | 临时文件路径 |
| R6 | 一次性草稿 |
| R7 | 重复规则 |
| R8 | 密钥/账号/Cookie/Token |
| R9 | Hermes 任何内部信息 |

**任一条 FAIL → REJECT**

## 硬限制

- 每任务最多 **3 条** candidate
- 候选池总量上限 **30 条**
- 超限时按 importance 排序，同等级按 created_at 先到先保留

## 输出格式

```markdown
## /memory:capture 提取报告
- 任务ID：[task_id]
- 证据路径：[path]
- 提取时间：[YYYY-MM-DD HH:MM]
- 候选池状态（提取前）：[N]/30

### 候选 1：CAND-YYYYMMDD-NNN
- 标题：[title] | 类型：[type]
- 准入：[A1:✅/❌] [A2:✅/❌] [A3:✅/❌] [A4:✅/❌] [A5:✅/❌] [A6:✅/❌] → 通过 [X]/6
- 拒绝：[R1-R9 全部 PASS / FAIL at R{X}: 原因]
- 判定：[PASS / REJECT]

### 汇总
- 通过数：[P]（上限 3）| 拒绝数：[R]
- 候选池状态（提取后）：[N+P]/30
- ⚠ 建议执行 `/memory dedupe` 进行去重检查
```
